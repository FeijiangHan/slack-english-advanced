# 01 · 俚语 & 口语词

🟢 随便用 · 🟡 熟人间 · 🔴 很随意/带粗口

## 感叹词 / 语气词

| 表达 | 中文意思 | 语气 | 例句 |
| --- | --- | --- | --- |
| **oof** | “哎呀 / 呃，这下麻烦了”，表示同情或尴尬 | 🟡 | *oof. yep, we'll find some other time, thanks.*（哎呀，好吧，那我们另找时间） |
| **whelp** | “好吧……（无奈）”，看到糟糕/无语的事时的叹气 | 🟡 | *whelp* + 贴一个让人无语的链接 |
| **yep / yeah** | 是的（比 yes 随意） | 🟢 | *Yep, that works for me.* |
| **Ohh I see** | 哦~原来如此 | 🟢 | *Ohh I see, thanks!* |
| **haha / lol / LOL** | 哈哈。小写 lol 只是礼貌性的笑，大写 LOL 才是真笑出声 | 🟢 | *this made me LOL* |
| **Lol, A and I are opposite** | 句首 Lol 用来缓和语气，不一定真好笑 | 🟢 | *Lol we have totally opposite opinions on this* |
| **Good lord.** | 天哪（震惊、无语） | 🟡 | *Good lord. This is a stats case study in exactly the wrong way.* |
| **Heck / What the heck** | 见鬼 / 管它呢（hell 的温和版） | 🟡 | *Heck, I'd even run it on CPUs if I had to.* |
| **How the heck do you…?!** | 你们到底是怎么……的？！（带佩服） | 🟡 | *How the heck do y'all stay caught up with all this stuff?!* |
| **hell, …** | 插入语，加强语气：“说真的/甚至” | 🔴 | *…hell, I'm pretty sure it wouldn't even get in.* |
| **wow** | 哇（发现新东西时） | 🟢 | *wow, agents can help us train these models now* |
| **A shame!** | 太可惜了！（常用来半开玩笑） | 🟢 | *I don't know your work well yet. A shame!* |
| **Yay / :tada:** | 耶 / 庆祝 | 🟢 | *Just posted a new paper! 🎉* |

## 常见口语词

| 表达 | 中文意思 | 语气 | 例句 |
| --- | --- | --- | --- |
| **y'all** | 你们（美南口语，现在全美年轻人都用） | 🟡 | *Okay y'all, here's the plan for this week.* |
| **folks** | 大家、各位（友好、不分性别） | 🟢 | *Hello folks, here's the bill from yesterday.* |
| **legit** | 靠谱的、正经的、真的 | 🟡 | *Slightly more legit post from a more legit group 😆* |
| **noob** | 菜鸟、新手 | 🟡 | *It wasn't working for me either! I thought maybe I was a noob.* |
| **slop / AI slop** | （AI 生成的）垃圾内容、水文 | 🟡 | *Many of these look like AI slop, so they shouldn't take long to review.* |
| **hot take** | 犀利/有争议的观点 | 🟢 | *Hot (but valid) take from…* / *Come with a few questions and hot takes!* |
| **ghost (sb)** | 已读不回、突然消失 | 🟢 | *I'd rather tell them than ghost someone who put in some effort.* |
| **drag (sb/sth)** | 公开吐槽、批评、“挂人” | 🟡 | *I'm not trying to drag this particular paper.* |
| **plug** | 打广告、推销一下 | 🟢 | *Sorry for the random plug — I'm giving away a fan.* |
| **life hack** | 生活小妙招 | 🟢 | *Life hack:* + 图 |
| **crack (a problem)** | 攻克、搞定（难题） | 🟢 | *There've been lots of recent efforts trying to “crack” this.* |
| **the word** | 消息、风声 | 🟢 | *Does anyone know what the word is about the next cycle?* |
| **a dump of** | 一大堆（随手整理的） | 🟢 | *Sharing a dump of recent papers I found interesting!* |
| **dump (a PDF) in** | 随手丢进去 | 🟢 | *Please dump a PDF of your draft in the folder by 11am.* |
| **bib crimes** | （玩笑）参考文献格式乱七八糟 | 🟡 | *Are these hallucinated references, or just bib crimes?* |
| **combat** | （玩笑）互怼、骂战 | 🟡 | *Another round of reviewer-author combat has dropped.* |
| **has dropped** | （新东西）发布了、出炉了 | 🟢 | *The new model has dropped.* |
| **acting weird** | 不正常、抽风 | 🟢 | *Is the server acting weird for anyone?* |
| **overkill** | 杀鸡用牛刀、过度了 | 🟢 | *Docker would be overkill for me.* |
| **heavy duty** | 重量级的、更重型的 | 🟢 | *…or something more heavy duty like Docker?* |
| **whoppingly / whopping** | 惊人地（大/长） | 🟡 | *Some calls took a whoppingly long time — like 1–2 hours.* |
| **crazy** | 疯狂的、离谱的 | 🟢 | *the model went into a crazy loop* |
| **not crazy about** | 不太喜欢（委婉） | 🟢 | *I'm not crazy about the first part of the title.* |
| **cool** | 不错、挺好（万能夸） | 🟢 | *That's really cool!* / *a cool paper* |
| **awesome** | 太棒了 | 🟢 | *Would be awesome if our school did something like this 👀* |
| **big name** | 大佬、大牛 | 🟢 | *He's a big name in this field.* |
| **enthusiast** | 爱好者、发烧友 | 🟢 | *I hear you're an interp expert and enthusiast.* |
| **onerous** | 繁琐的、麻烦的（偏书面但常用） | 🟢 | *The application was a bit onerous.* |
| **painless** | 不费劲的、顺利的 | 🟢 | *We applied a while ago — fairly painless.* |
| **impromptu** | 临时起意的 | 🟢 | *We can walk over impromptu after the talk.* |
| **ish / ~10ish** | 大约 | 🟢 | *~10ish years* / *around 5ish?* |
| **one (1)** | 玩笑式强调“就一个” | 🟡 | *I saw this thrown around in one (1) space and one (1) other.* |

## 学术圈黑话

| 表达 | 中文意思 | 例句 |
| --- | --- | --- |
| **share-out** | 分享会（每人展示一下） | *We'll do a paper draft share-out for feedback.* |
| **n-minute madness** | 每人几分钟快速自我介绍/汇报 | *We'll kick off with n-minute madness.* |
| **straw poll** | 非正式的快速投票 | *The straw poll indicated some people are willing to review.* |
| **temperature check** | 摸底、快速了解大家态度 | *Can I get a quick temperature check on…?* |
| **on the market** | 在找工作 | *Do you know anyone who's on the market?* |
| **pipeline** | （人才）输送渠道 | *a pipeline recruitment program* |
| **blockers** | 卡住你的问题 | *What are your current blockers?* |
| **fishing expedition** | 漫无目的地乱试（直到找到“显著”结果） | *It's a fishing expedition — try enough things and something will pop out.* |
| **embarrassingly parallel** | 天然可并行的（术语，但口语里常用） | *It's for embarrassingly parallel work.* |
