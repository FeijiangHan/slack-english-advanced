# 04 · 习语 & 短语动词

## 习语 (Idioms)

| 表达 | 中文意思 | 例句 |
| --- | --- | --- |
| **cut sb (a little) slack** | 对某人宽容一点、网开一面 | *They're not from an English-speaking school, so I was willing to cut them a little slack.* |
| **take a harder line** | 采取更强硬的态度 | *I'd usually take a harder line or just ignore it.* |
| **food for thought** | 值得思考的东西 | *…food for thought on how we can push this further.* |
| **on the cusp of** | 即将、处在……的边缘 | *We are on the cusp of large-scale automation.* |
| **return the favor** | 回报人情 | *Happy to return the favor at some point!* |
| **second-guess (oneself)** | 事后怀疑、反复犹豫 | *The model kept running, trying to second-guess itself.* |
| **take a chance (on)** | 冒险试一试 | *Be ready to take a chance on an opportunity that presents itself.* |
| **a fishing expedition** | 漫无目的地乱找证据 | *It's basically a fishing expedition.* |
| **under the hood** | 内部机制、底层 | *It shows exactly which features it uses under the hood.* |
| **on the surface** | 表面上 | *It looked reasonable on the surface but went quietly wrong.* |
| **the big picture** | 大局、宏观问题 | *What's the big-picture question you'd like to answer?* |
| **a piece of the pie** | 其中一部分 | *…and which piece of that pie is your current paper?* |
| **make what you will of it** | 你自己判断吧 | *Make what you will of the greeting :P* |
| **the moral of the story** | 这件事的教训 | *Moral of the story: use it to double-check code.* |
| **in a nutshell** | 简而言之 | *In a nutshell, it downloads mail and labels it.* |
| **no way (am I …)** | 绝不 | *No way am I sharing my email with a cloud provider!* |
| **not a great use of your time** | 不值得花时间 | *Doing more is not a great use of your time.* |
| **a bad time (for many)** | 不是好时候（大家都忙） | *I know it's a bad time for many.* |
| **finally has a home** | 终于有着落了 | *The workshop finally has a home: at COLM this October!* |
| **badly timed** | 时机不好的 | *a (badly timed) trip tomorrow* |
| **last-minute** | 最后一刻的、临时的 | *a last-minute conflict* / *Kinda last minute, but…* |
| **first-come, first-served** | 先到先得 | *Up to 20 spots, first-come, first-served.* |
| **stress-test** | 压力测试、严格检验 | *Length is a meaningful stress-test.* |
| **deserves a second look** | 值得再看一眼、重新审视 | *This old baseline deserves a second look.* |
| **(for) awhile** | 一段时间 | *I've wanted to formalize this idea for awhile.* |
| **out of the blue / unexpectedly** | 突然 | *I unexpectedly lost access to my account.* |
| **literally** | 字面意义上地；（口语）真的就 | *Literally by 10am I had started a new collaboration.* |
| **just plain [adj]** | 就是纯粹的…… | *just plain irresponsible* |
| **in exactly the wrong kind of way** | 以完全错误的方式 | *It's a case study, but in exactly the wrong kind of way.* |

## 短语动词 (Phrasal Verbs)

| 表达 | 中文意思 | 例句 |
| --- | --- | --- |
| **reach out (to sb)** | 联系某人 | *Please reach out if you're interested!* |
| **ping sb** | （在 Slack 上）戳一下、提醒 | *Ping me if so.* |
| **figure out** | 弄明白、想办法解决 | *Hope you can figure out the shared items!* |
| **kick off** | 开始、启动 | *We'll kick off the colloquium this Wednesday.* |
| **start (sth) back up** | 重新开始 | *We're starting the weekly meeting back up!* |
| **flesh out** | 充实、完善（想法） | *It's ok if you're still fleshing out an idea.* |
| **float (an idea)** | 提出（想法）看看反应 | *I thought I'd float it to see what people think.* |
| **push back (on)** | 反驳、提出异议 | *…fewer dialogues where you have to push back on a response.* |
| **pair up (with)** | 结对、组队 | *You can also pair up with others!* |
| **swap (sth) out** | 换掉 | *I still have to swap the models out frequently.* |
| **swap (A with B)** | 交换 | *Could we swap our meeting spots?* |
| **line up / have sb lined up** | 安排好 | *We have someone lined up to present until December.* |
| **sign up (for)** | 报名 | *Please sign up to meet the speaker.* |
| **fill out** | 填写（表格） | *Please fill out this short survey by Friday.* |
| **drop a message** | 发条消息 | *Please drop a message when you're done paying.* |
| **grab (lunch / appetizers / a coffee)** | 去吃点/喝点 | *Thinking about grabbing lunch at the dining hall.* |
| **walk over** | 走过去 | *We'll meet near the kitchen and walk over.* |
| **hang out** | 一起玩、待着 | *a nice chance to meet people and hang out* |
| **call ahead** | 提前打电话（预约） | *I can call ahead, but they may not take reservations.* |
| **get to (sth)** | 抽出时间做 | *I haven't gotten to it yet.* / *Sorry I didn't get to it earlier.* |
| **get through (sth)** | 看完、熬过 | *just got through the intro* / *how people got through their dark times* |
| **run short (of)** | 不够用 | *If I run short, it's usually a time limit.* |
| **hold up (resources)** | 占着、耽误 | *These jobs hold up GPUs even after they finish.* |
| **come across** | 偶然看到 | *I've come across some very recent papers on this.* |
| **stumble across** | 偶然发现 | *Stumbled across this — looks promising.* |
| **build off / build on** | 在……基础上 | *a paper building off last year's workshop paper* |
| **cut down (sth)** | 削减 | *I'll cut down the readings from 3 to 2.* |
| **keep track of** | 跟进、记录 | *help keep track of missing reviews* |
| **stay / keep caught up (with)** | 跟上（最新进展） | *How do y'all stay caught up with all this?* |
| **spread the word** | 帮忙宣传 | *Please help us spread the word!* |
| **pass (sth) along / on** | 转达、转发 | *I'll pass this along to the host!* |
| **sit tight / stay tuned** | 稍等 / 敬请期待 | *Stay tuned for more information!* |
| **check out** | 看看 | *Check it out if you're interested!* |
| **take a look (at)** | 看一下 | *Could you take a look at Table 1?* |
| **read / skim through** | 通读 / 略读 | *Please read/skim through these papers.* |
| **come with / come prepared** | 带着……来 / 做好准备来 | *Come with a few questions and hot takes!* |
| **end up (doing)** | 结果却…… | *…but ended up canceling the whole event.* |
| **turn out (to be)** | 结果是 | *It turned out to be a subtle language nuance.* |
| **point (sb) to** | 给某人指出 | *Could someone point me to the right process?* |
| **opt out (of)** | 选择退出 | *You can opt out of us saving your submission.* |
| **grapple with** | 努力解决（难题） | *take the time to grapple with complex issues* |
| **wrap up** | 结束、收尾 | *for anybody wrapping up a PhD* |
| **sticking with (it)** | 继续沿用 | *It worked well last year, so we're sticking with it.* |
| **roll out / keep rolling out** | 推出 / 不断推出 | *as new models keep rolling out* |
