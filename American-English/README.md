# 🇺🇸 American English：真实场景里的地道表达

这里收集的是**美国研究生 / 实验室 / 学术圈同事在 Slack 上真实使用的英语**——不是教科书句子，而是大家每天发消息时真正会打出来的话。

> 素材来源：我所在的 Slack 工作区里的所有频道（公告、闲聊、快速提问、论文分享、求职、组内频道、私信等）。
> 为保护隐私，**所有例句都已改写、去掉人名和具体内容**，只保留句式和语气。

## 🧭 怎么用

1. **先看 03**：按场景背句型，最快能用上。
2. 遇到看不懂的词 → 在 01 / 02 / 04 里 `Ctrl+F`。
3. 每周做一次 06 的练习，把答对率记下来。
4. 每个条目都标了语气：
   - 🟢 随便用（同事/朋友都行）
   - 🟡 偏口语，跟熟人用
   - 🔴 很随意 / 带点粗口，正式场合别用

## 🔄 维护方式

- 每次从 Slack 收集新表达后，追加到对应文件，并在 [CHANGELOG.md](CHANGELOG.md) 记录日期和新增条目数。
- 条目格式统一为：**表达 | 中文意思 | 语气/用法 | 例句**。
- 例句一律改写、去名字，不直接搬运原消息（尤其是私密频道）。
